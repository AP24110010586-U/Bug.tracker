Quick guide

Priority — how soon it must be fixed.

Critical = fix immediately, High = this sprint, Medium = soon, Low = when there is time.

Severity — how badly it breaks the software.

Blocker = system unusable, Major = main feature broken, Moderate = workaround exists, Minor = cosmetic.

A unique ticket number (like BUG-1015) is created for you automatically.
